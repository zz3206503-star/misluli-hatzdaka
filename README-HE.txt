מסלול הצדקה חי — גרסה 11 המקורית של Work — מותאמת לתיקייה ראשית אחת ב-GitHub Pages

כל 12 קובצי האתר והנתונים נמצאים ישירות באותה תיקייה, בלי תיקיות פנימיות.
אין תמונות של בתי כנסת. שלושת קובצי icon הם רק סמלים קטנים להתקנת האפליקציה.

המאגר המלא והבלתי-משונה הוא places.json: 4,802 רשומות, 34,013 מועדי מניינים.
app.js, i18n.js, styles.css ויתר קוד המקור המקורי של Work נשמרו ללא שינוי.
האתר טוען את הנתונים מתוך ./places.json (לא data/places.json).

מה הותאם בלבד:
- הסרה של קישור לדף review/ עם תמונות שהוסר.
- sw.js: הסרת תמונות וקבצים שאינם קיימים, שמירת נתיב places.json בשורש,
  ושינוי גרסת המטמון כדי למנוע בעיה בטעינת הגרסה הישנה.

איך מעלים ל-GitHub Pages:
1. מחלצים את ה-ZIP. כל הקבצים יהיו בתיקייה אחת, בלי תתי-תיקיות.
2. ב-GitHub, בתוך שורש repository, בוחרים Add file > Upload files.
3. בוחרים את כל הקבצים שבתיקייה שחולצה ומבצעים Commit changes.
4. מוודאים ש-places.json, app.js, index.html ו-sw.js באותה שורה ברשימה.
5. פותחים את אתר GitHub Pages, מבצעים רענון מלא; אם יש קובץ קודם
   ב-Cache נסו חלון גלישה בסתר כדי לבדוק את הגרסה האחרונה.

אל תעלו את קובץ ZIP עצמו לתוך המאגר במקום הקבצים: GitHub Pages אינו מחלץ אותו.
אין לצפות שהאתר יפעל במלואו כאשר פותחים את index.html כקובץ מקומי:
יש להפעילו דרך HTTPS או שרת HTTP כדי לטעון את places.json.
