מה נכלל
---------
• מסך פתיחה עם כפתור אחד: "מסלול חי".
• שחרית בלבד: זמני CLICK613 גיליון 256 (15–20 בנובמבר 2026), חוברות עמודים 2 ו-21–31.
• 210 כתובות/בתי כנסת עם שחרית ו-40 מיקומים נוספים מהמפה שאין להם שעה מודפסת בחוברת.
• 558 זמני שחרית לימים הרגילים, 442 זמני שחרית ליום ראשון; כל שעה היא כפתור נפרד.
• בכל בית כנסת: שעות חול, ובנפרד הערת שעות יום ראשון. ביום ראשון משתמשים בזמני יום ראשון במקום שעות החול.
• לחיצה על שעה מסמנת את המניין באדום ומותירה אותו ברשימה. לחיצה נוספת מבטלת סימון.
  הסימון נשמר בדפדפן במכשיר הנוכחי לפי התאריך. התאריך הבא מתחיל ללא סימונים.
• מיקום GPS חי (עם אישור), הצעות מסלול שמתעדכנות, ניווט Waze/Google Maps ומפה חינמית.
• אפשרות בחירת אזור אם לא ניתן להפעיל GPS, וחיפוש בתי כנסת.
• תיקון מיקום בידי המשתמש מתוך רשימת הצעות או בקואורדינטות/נקודה במפה.
• ייבוא קובצי CSV, JSON, GeoJSON, KML של מיקומים בלבד; יצוא תיקוני מיקומים.

   בנקודות אזוריות משתמשים בכתובת עצמה לניווט Waze/Google Maps, ולא בקואורדינטת מרכז האזור.

5. חלק משעות החוברת מועתקות מחורף קודם ולא אושרו מחדש, וחלק משתנות עם הנץ;
   יש לאמת זמן לפני נסיעה.

התקנה ב-GitHub Pages — לא ב-AlwaysData
--------------------------------------
1. חלץ את ZIP למחשב או לטלפון.
2. פתח GitHub וצור Repository חדש (רצוי Public לחשבון GitHub Pages חינמי).
3. העלה את הקבצים שבתוך ZIP *ישירות לתיקייה הראשית של המאגר*:
   index.html, app.js, style.css, data.json, sw.js, manifest.webmanifest, icon.svg, icon-192.png, icon-512.png.
   אל תעלה רק את קובץ ZIP, משום ש-GitHub Pages אינו פותח אותו אוטומטית כאתר.
4. עבור ל-Settings > Pages > Build and deployment.
5. תחת Source בחר Deploy from a branch, ואז main ו-/(root) ולחץ Save.
6. פתח את כתובת האתר שיופיע בעמוד Pages; אשר הרשאת מיקום בדפדפן.
7. כדי להשתמש כיישומון בטלפון: Chrome > ⋮ > הוסף למסך הבית / התקן אפליקציה.

הגבלות
-------
• זו אפליקציית אתר סטטית. אין שרת, מפתח API, חשבון משתמש או תשלום.
• מיקום GPS פועל באתר HTTPS ובהסכמת המשתמש; אם ההרשאה נחסמת אפשר לבחור אזור.
• זמנים ומרחקים במסלול משוערים; הדגמת OSRM עשויה לספק זמן נסיעה על כבישים
  אבל אינה מקור לפקקי תנועה חיים, ללא הבטחת זמינות. לצורך פקקים אמיתיים פתח Waze.
• הרשימה ב-Google Maps היא "רשימה שמורה" ולא Google My Maps. הקישור משמש לפתיחה,
  אבל אינו נותן לסנכרן באופן אוטומטי רשימה פרטית לאתר סטטי.
  אפשר לייבא קובץ ייצוא מיקומים עדכני ולהחיל תיקונים מקומיים.
• תיקונים וסימונים שמורים בדפדפן, לא בחשבון GitHub ולא בצ'אט.
  אחרי תיקונים לחץ "ייצא תיקוני מיקום" ושמור קובץ JSON להעברה או לצורך גרסה חדשה.
• מיקומים המשוערים מסומנים ומסלולי GPS שלהם פחות מדויקים; בדוק את הכתובת בווייז.
