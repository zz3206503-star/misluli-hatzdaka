מסלול הצדקה חי — גרסת Work המקורית 11, חבילה נקייה ללא צילומי בתי כנסת

זהו מבנה האתר המקורי של Work. העיצוב, התרגום, החיפוש, מסכי המניינים,
מפת בתי הכנסת, כפתורי הניווט, קיצור הדרך וההתקנה נשארו בקובצי המקור.
לא בוצעו שינויים בלוגיקת המסלולים ובנתונים עצמם.

מאגר הנתונים: data/places.json
הקובץ מכיל את כל 4,802 הרשומות ו-34,013 זמני המניינים ממאגר Work המקורי
לרבות הערות, שמות בשפות שונות, שעות לימים שונים והחלטות שנשמרו בגרסה 11.
הקובץ זהה בדיוק לבית-הנתונים המקורי. לא נערך חיפוש חדש ולא הומצאו שעות.

מה הוסר: 44 צילומי ההשוואה, מסך הסקירה review והקישור אליו.
מה נשאר: 3 סמלי האפליקציה (icon-64/192/512.png) – אינם צילומי בתי כנסת,
ונדרשים להצגת הסמל ולהתקנת האפליקציה על מסך הבית.
דף השוואת חוברות מונסי ללא תמונות נשאר: comparison.html.

שני שינויי קוד טכניים בלבד:
1. app.js קורא את המאגר מתוך data/places.json במקום places.json בשורש.
2. sw.js שומר בזיכרון המטמון את נתיבי הקבצים התקפים בלי התמונות שהוסרו;
   מספר המטמון עודכן כדי למנוע שגיאות מהגרסאות הקודמות.
   בעמוד הראשי הוסר רק קישור הבדיקה review שהוסר.

העלאה ל-GitHub Pages:
חלץ את קובץ ZIP. העלה את קובצי השורש למאגר ואת הקובץ data/places.json
בנתיב data/places.json בדיוק (התיקייה data צריכה להיות בתוך שורש האתר).
אין להעלות את ה-ZIP כפי שהוא: GitHub Pages לא מחלץ ZIP אוטומטית.
אין להעביר את places.json לשורש בלי התאמה של app.js.
לאחר Commit פתח את האתר בדפדפן, בצע רענון מלא כדי שגרסת SW החדשה תפעל.
