מסלול הצדקה חי — אתר סטטי / PWA ל־GitHub Pages

העלאה:
1. צור מאגר GitHub והעלה את כל הקבצים מהתיקייה (לא רק את קובץ ה־ZIP).
2. Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
3. פתח את כתובת ה־HTTPS שהתקבלה. GPS פועל רק בדף מאובטח ובאישור המשתמש.
4. מסך ראשי -> מסלול חי. בנקודות ללא מיקום ודאי מופיעה אזהרה.
5. התקנת אפליקציה: כפתור התקנה, או תפריט Chrome -> התקנת אפליקציה / הוספה למסך הבית.

מקורות נפרדים ולא מעורבבים:
- בתי כנסת.csv (Google Takeout) — 473 קישורי מקומות, הוכנסו כולם בלי הערות.
- luach (1).pdf — חוברת CLICK613, פרשת ויצא, 15–20.11.2026. רק שחרית.
- Parshas Vayaitzai.pdf — חוברת Monsey Zmanim, פרשת ויצא תשפ״ז. רק שחרית.
- צילומי מסך מ־Sinagoga 1.zip — פוענחו ידנית 34 בתי כנסת עם שעות שחרית קריאות. תאים לא ברורים או תלויי עונה לא הוכנסו; החומר אינו ייצוא אוטומטי של האתר שמופיע בצילומים.

דיוק:
473 מיקומי המפה חושבו ממזהי מיקום S2 שבקישורי Google Maps. זו קירבה גאוגרפית, לא אימות של פתח הכניסה.
מיקומים שנמצאו רק בחוברות ללא התאמה לרשימה מופיעים לפי מרכז אזור משוער, עם ציון מפורש. ניווט אליהם מחפש כתובת, ולא משתמש במרכז האזור.
מסלול חי נעזר בחישוב קו אווירי ובהערכת זמן נסיעה, לא במידע פקקים חי. לאחר לחיצה על Waze, Waze יכול לספק תנועה מעודכנת.
הזמנים הם צילום־מצב של החוברות המתוארכות; זמנים משתנים, זמני ותיקין תלויי נץ או רישומים עמומים לא הומצאו.
נתוני ה־GPS וסימוני „הייתי במניין” נשמרים בדפדפן במכשיר ולא נשלחים לשרת. סימוני המניינים נשמרים לפי תאריך.
